Topten theme options panel with responsive fields, groups, import/export, and custom fonts for WordPress themes.

== Description ==

Topten Simple Theme Options (STO) registers a Theme Settings admin experience: sections, field types (color, typography, dimension, repeaters, and more), responsive breakpoints, and theme helpers such as `sto_get_option()`.

Install this fork as `battery-simple-theme-options` (not `simple-theme-options` on WordPress.org — that slug is used by another plugin).

== Installation ==

1. Upload the plugin folder to `wp-content/plugins/battery-simple-theme-options/`.
2. Activate **Topten Simple Theme Options** under **Plugins**.
3. Open **Theme Settings** in the admin menu and register fields from your theme.
